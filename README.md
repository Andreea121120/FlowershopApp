# Online Flowershop App

Web application for an online flower shop, built with ASP.NET MVC, featuring two user roles:

- **Administrator** – manages the product catalog (add, edit, delete, prices).
- **Client** – browses products, places orders, views order/activity history, and makes payments.

## Features
- Authentication and role-based authorization
- Product management (CRUD) – admin
- Order placement and viewing
- User activity history
- Payment processing

## Technologies
- **Backend:** ASP.NET MVC, C#
- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Database:** SQL Server
